## 📌 Overview

**SARATHI-VAHAN (Attack on Tokens)** is an interactive, satirical web project demonstrating the worst anti-patterns and "dark UX" mechanics often experienced on overloaded bureaucratic portals. 

Built with pixel-perfect official styling—complete with Ashoka Chakra insignias, tricolor accents, live fake server latency meters, and SSL security badges—the portal playfully frustrates users attempting to book an ordinary driving license slot.

---

## 😈 Featured Dark Patterns & Frustrations

### 1. 🎚️ Floating-Point Date of Birth Sliders
*Manual entry is disabled under fake "Anti-Tampering Circular RTO/IT/2026/117".*  
Users are forced to specify their Year, Month, and Day using floating-point sliders with a `step="0.0001"`, turning a simple birthday entry into a test of surgical hand precision.

### 2. ⚡ The Vanishing Slot Snatcher
Every green "Available" slot turns red and locks into "Booked" the split-second your cursor hovers over it, taunting you with:  
> *"Slot allocated to Applicant #8492 just 0.1s ago."*  
The only perpetually available slot? The **5:15 AM Agricultural Heavy Tractor Track**.

### 3. 💸 Sneak-into-Basket Statutory Surcharges
Selecting a standard vehicle category (LMV or MCWG) secretly auto-injects hidden levies into your bill:
- **Mandatory High-Risk Highway Indemnity Levy:** ₹1,450
- **Rural Cattle Crossing Infrastructure Surcharge:** ₹780
- **e-Seva Digital Signature Convenience Fee:** ₹99  
*(Attempting to uncheck these riders automatically wipes your entire license selection).*

### 4. 👁️ The Inverted Snellen Tumbling-E Eye Check
To verify your vision, you must identify the orientation of the tumbling "E". However, the moment your cursor enters the direction pad to answer, **the visual chart flips 180° upside-down** ("Dynamic Perceptual Calibration Active").

### 5. 🏃 The Teleporting Self-Declaration Checkbox
Under Step 5, the required "I Agree" checkbox flees across the four corners of the container whenever your cursor gets within 35 pixels.

### 6. ⏳ The 180s Session Lock & Phantom Queue
A sticky urgency banner ticks down from 3 minutes. If the timer expires or you hesitate, your reservation lock is revoked, and you are kicked to queue position `#5,900+`.

### 7. 💥 The 99% Payment Gateway Crash
Successfully navigating all steps leads to an authentic-looking multi-stage payment modal (Aadhaar e-KYC, token encryption). At **99%**, the progress bar turns red, fails with:
> `Error code: 0xDEADBEEF: User interaction hesitation exceeded allowable regulatory latency threshold.`  
The entire form resets to blank.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or later recommended)
- `npm` or `pnpm`

### Installation & Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SandipBarela/attack-on-tokens.git
   cd attack-on-tokens
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in your browser:**  
   Navigate to [http://localhost:3000](http://localhost:3000) (or `http://localhost:3001` if port 3000 is occupied).
